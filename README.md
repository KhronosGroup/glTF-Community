
# glTF-Community

Community-contributed extensions and resources for the [glTF 2.0](https://www.khronos.org/gltf/) specification, maintained under Khronos Group management.

## Overview

This repository hosts glTF 2.0 extensions developed and contributed by the glTF community. Content here is not part of the core glTF specification. Contributions come from a variety of sources and are available under a range of licenses — check individual extension directories and [`LICENSE.md`](./LICENSE.md) for details.

## Extensions

**[Browse available extensions →](./extensions/README.md)**

Extensions are organized by vendor prefix under `extensions/`. Each extension includes its own specification document and license information.

## Contributing

Community contributions are welcome. Before submitting, please review:

- **[CONTRIBUTING.md](./CONTRIBUTING.md)** — how to contribute an extension or other material
- **[LICENSE.md](./LICENSE.md)** — licenses in use across this repository
- **[COPYING.md](./COPYING.md)** — guidance on reusing or copying files and extensions
- **[vendors/README.md](./vendors/README.md)** — how to request a new vendor prefix

## Scope

At this time, this repository contains glTF 2.0 extensions only.

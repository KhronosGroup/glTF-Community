# MSFT extensions

All extensions in this directory were created by Microsoft. They were originally published in the [main glTF repository](https://github.com/KhronosGroup/glTF) and have been moved here unchanged.

| Extension Name | Brief Description |
| -------------- | ----------------- |
| [`MSFT_lod`](MSFT_lod/README.md) | Specify levels of detail (LOD) at the node or material level. |
| [`MSFT_packing_normalRoughnessMetallic`](MSFT_packing_normalRoughnessMetallic/README.md) | Alternate texture packing: Normal (RG), Roughness (B), Metallic (A). |
| [`MSFT_packing_occlusionRoughnessMetallic`](MSFT_packing_occlusionRoughnessMetallic/README.md) | Alternate texture packings of occlusion, roughness and metallic, plus a two-channel normal map. |
| [`MSFT_texture_dds`](MSFT_texture_dds/README.md) | Specify textures using the DirectDraw Surface file format (DDS). |

# glTF Community Extensions

This directory contains community-contributed extensions to the glTF 2.0
specification. Each extension is maintained by its owning organization and is
independently licensed.
**Before using any extension, read and understand its license terms.** License
information is provided within each extension's folder.

For information on contributing an extension, see
[CONTRIBUTING.md](../CONTRIBUTING.md). For prefix registration instructions, see
[vendors/README.md](../vendors/README.md).

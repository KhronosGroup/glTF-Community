# GODOT extensions

All extensions in this directory are created by the developers of Godot Engine, a 2D and 3D game engine.

These extensions serve the needs of Godot Engine, but are not limited to use in Godot Engine. Other vendors are encouraged to implement any of these extensions in their own software, for any reason, such as if they wish to improve their software's interoperability with Godot Engine, or if they want the functionality for any other purpose.

| Extension Name      | Brief Description                                                               |
| ------------------- | ------------------------------------------------------------------------------- |
| `GODOT_single_root` | Flag files as having a single root node, skipping the implicit extra root node. |

All GODOT extensions are licensed under CC0-1.0.
